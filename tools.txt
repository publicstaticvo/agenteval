- ChEMBL_search_similar_molecules: Search for molecules similar to a given SMILES, chembl_id, or compound or drug name, using the ChEMBL Web Services. Note: This tool is designed for small molecule compounds only.
- PubChem_get_compound_by_CID: Retrieve compound information from PubChem using a CID.
- ADMETAI_predict_physicochemical_properties: Predicts physicochemical properties (molecular weight, logP, hydrogen bond acceptors/donors, Lipinski, QED, TPSA, etc.) for a list of SMILES.
- ADMETAI_predict_CYP_interactions: Predicts CYP enzyme interactions for a list of SMILES.
- ADMETAI_predict_BBB_penetrance: Predicts blood‑brain barrier penetrance for a list of SMILES.
- ADMETAI_predict_toxicity: Predicts toxicity endpoints (AMES, Carcinogens, DILI, LD50, Skin Reaction, hERG) for a list of SMILES.
- ADMETAI_predict_bioavailability: Predicts bioavailability endpoints for a list of SMILES.
- ADMETAI_predict_nuclear_receptor_activity: Predicts nuclear receptor activity (AR, ER, AhR, PPAR‑γ, etc.) for a list of SMILES.
- ADMETAI_predict_stress_response: Predicts stress‑response endpoints (ARE, ATAD5, HSE, etc.) for a list of SMILES.
- ADMETAI_predict_solubility_lipophilicity_hydration: Predicts solubility, lipophilicity, and hydration free energy for a list of SMILES.
- alphafold_get_prediction: Retrieve full AlphaFold 3D structure predictions for a given protein. IMPORTANT: The qualifier must be a UniProt ACCESSION.
- alphafold_get_summary: Retrieve summary details of AlphaFold 3D models for a given protein.
- alphafold_get_annotations: Retrieve AlphaFold MUTAGEN annotations for a given UniProt accession.
